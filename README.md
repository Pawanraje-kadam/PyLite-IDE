## ✨ About
PyLite-IDE is a lightweight, accessible, and beautiful web-based Python IDE designed to make coding delightful. It’s perfect for learners, educators, and anyone who wants to prototype Python code instantly — right in the browser.

Why PyLite-IDE?
- Instant access — open and code in seconds ✅  
- Minimalist UI for maximum focus 🎯  
- Runs in-browser (safe sandboxing) 🔒  
- Accessible & keyboard-first design ♿

---

## 🔧 Features
- 📝 Elegant code editor with syntax highlight, line numbers, and multi-cursor
- ▶️ Run Python code in-browser with instant output
- 🗂️ File explorer: create, rename, delete files and folders
- 🧭 Beginner-friendly templates & snippets
- 🎨 Light & Dark themes + font-size controls
- ⌨️ Keyboard shortcuts for a fast workflow
- 📤 Export projects as ZIP / Gist
- ♻️ Fast, responsive UI — mobile & tablet friendly

## 🚀 Quick Start

Clone, install, and run:

```bash
# Clone
git clone https://github.com/Pawanraje-kadam/PyLite-IDE.git
cd PyLite-IDE

# Install dependencies
npm install
# or
yarn

# Start dev server
npm run dev
# or
npm start
